# Cloudflare Worker snapshots

Archived versions of the API Worker, webinar relay, and isolated preview Worker, plus release and deployment guards. These are separate snapshots of different workloads. Each relies on Cloudflare bindings supplied at deployment time.

The archived API bundle includes code from [@cloudflare/containers 0.3.7](https://github.com/cloudflare/containers/tree/298169f4aaba82e7b712458b7c6b14fc3e40ad78).
